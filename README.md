## About

I lead security operations and conduct penetration tests at AXE.AI. My work spans web applications, networks, and connected devices. I also develop tools that reduce repetitive work during assessments and study how hardware, firmware, and emerging technologies affect the security of the systems they support. [Professional background](https://pmiswohio.org/calendar?eventId=46043)

My research interests include embedded systems, IoT and medical device security, wireless protocol analysis, and AI-assisted security testing.
